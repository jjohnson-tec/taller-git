## Proyecto ejemplo (estructura Python)

He añadido una estructura mínima de proyecto Python para que los estudiantes puedan ver ejemplos de código y pruebas.

- `src/taller`: paquete de ejemplo con función `greet()`.
- `tests`: pruebas con `pytest`.
- `pyproject.toml` y `requirements.txt` para dependencias.

Instrucciones rápidas:

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1   # PowerShell
pip install -r requirements.txt
pytest
```
